# Legacy UI/UX Reference

## Registration Flow
- Centered card layout with a 4-step indicator (circles with numbers).
- **Step 1: Academic** (Org, Course, Year, Section dropdowns). Org dropdown contains logos and dynamically changes header color/image.
- **Step 2: Personal** (Name, ID, Email, Address, DOB, Photo upload).
- **Step 3: Emergency** (Name, Number, Address with "Same as residential" checkbox).
- **Step 4: Review** (Table summary and checkbox for certification).
- Beside the form (desktop) is a 3D flippable ID card preview updating live as the user types.

## Admin Panel
- Bento-grid style layout mentioned in docs/README.
- Settings page has tabs/sections for managing Org, Courses, Sections.
- Course view uses grouped accordion/tables for years and sections.
- Bulk select checkboxes for printing and deleting.
